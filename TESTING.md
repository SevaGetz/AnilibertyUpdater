## Как протестировать самостоятельно

1. Настройте config.json с вашими данными qBittorrent
2. Добавьте реальный ID релиза:
   ```bash
   ./manage.sh add 10159
   ```
3. Выполните проверку:
   ```bash
   ./manage.sh check
   ```
4. Проверьте логи:
   ```bash
   cat auto_update_torrents.log
   ```

## Известные особенности

- При первом запуске торрент добавляется в qBittorrent
- При повторных проверках скрипт определяет отсутствие обновлений
- Когда выйдет новая серия, скрипт автоматически:
  - Скачает новый торрент-файл
  - Удалит старый торрент (файлы останутся)
  - Добавит новый торрент
  - qBittorrent продолжит скачивание с того же места
