# Обновление v2.0 - Поиск по названию и пути сохранения

## 🎉 Новые возможности

### 1. 🔍 Поиск релизов по названию

Больше не нужно искать ID на сайте вручную!

```bash
# Поиск
./manage.sh search "Хайбара"

# Результат: список релизов с ID, названиями, годом и количеством эпизодов
```

### 2. 📁 Индивидуальные пути сохранения

Каждый релиз может сохраняться в свою папку:

```bash
# Добавить с путем
./manage.sh add 10159 /downloads/anime/haibara

# Интерактивное добавление по названию
./manage.sh add-by-name "Доктор Стоун" /downloads/anime/dr-stone
```

### 3. 🎯 Интерактивный выбор релиза

```bash
./manage.sh add-by-name "Хайбара"

# Скрипт покажет найденные релизы и предложит выбрать нужный
```

## 📋 Изменения в конфигурации

### Старый формат (v1.0):
```json
"tracked_releases": [10159, 10162]
```

### Новый формат (v2.0):
```json
"tracked_releases": {
    "10159": {
        "name": "Вторая юность Хайбары",
        "save_path": "/downloads/anime/haibara"
    },
    "10162": {
        "name": "Доктор Стоун",
        "save_path": ""
    }
}
```

### Новый параметр в qbittorrent:
```json
"qbittorrent": {
    "download_path": "/downloads/anime"
}
```

## 🔧 Технические улучшения

- ✅ Поддержка qBittorrent API v4.1+ и v4.6+
- ✅ Обработка HTTP 204 для авторизации
- ✅ Обработка JSON ответов при добавлении торрентов
- ✅ Обработка конфликтов (торрент уже существует)
- ✅ Автоматическое получение названий релизов через API
- ✅ Сохранение путей в state.json

## 📚 Новые команды

```bash
./manage.sh search "название"              # Поиск релизов
./manage.sh add ID [PATH]                  # Добавить с путем
./manage.sh add-by-name "название" [PATH]  # Интерактивное добавление
```
