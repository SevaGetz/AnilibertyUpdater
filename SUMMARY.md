### Как начать использовать:

```bash
# 1. Установка
./manage.sh install

# 2. Настройка config.json
# Укажите данные для qBittorrent Web UI

# 3. Добавление релиза
./manage.sh add 10159

# 4. Тестовая проверка
./manage.sh check

# 5. Запуск в фоне
./manage.sh start

# 6. Просмотр логов
./manage.sh logs
```

### Как найти ID релиза:

1. Откройте страницу релиза на https://aniliberty.top
2. ID находится в URL: `https://aniliberty.top/release/10159` → ID = 10159

### Принцип работы:

1. Скрипт периодически (каждые 5 минут по умолчанию) проверяет каждый релиз
2. Получает список торрентов и выбирает самый свежий
3. Сравнивает hash с сохраненным в state.json
4. При обнаружении обновления:
   - Скачивает новый торрент-файл
   - Удаляет старый торрент из qBittorrent (файлы остаются!)
   - Добавляет новый торрент
   - qBittorrent продолжает скачивание с того же места
